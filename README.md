# channel-autoposter

Контент для Telegram-канала на месяц + автопостинг по расписанию.

1. **Бриф** (`brief.json`): тема, аудитория, тон, рубрики, реальные факты, что запрещено.
2. **Генерация** (`generate.py`): Claude составляет контент-план на 30 дней и пишет 30 постов → `posts.csv`.
   Все посты — черновики.
3. **Проверка человеком**: `posts.csv` открывается в Excel — правите тексты, даты, время.
   В боте — предпросмотр и одобрение.
4. **Публикация** (`bot.py`): в канал по расписанию уходят **только одобренные** посты.

## Запуск
```bash
python -m venv venv
venv\Scripts\pip install -r requirements.txt
copy .env.example .env      # BOT_TOKEN, ANTHROPIC_API_KEY, ADMIN_ID
python generate.py          # → posts.csv (30 черновиков, старт с завтра)
python bot.py
```
Добавьте бота **администратором канала** с правом публикации — он сам запомнит канал и напишет вам.

## Команды (в личке с ботом, только для ADMIN_ID)
| Команда | Что делает |
|---|---|
| `/plan` | ближайшие 7 постов: ✅ одобрен, 📝 черновик |
| `/preview 5` | пост №5 так, как он выйдет в канале |
| `/approve 5` · `/approve 1 2 3` · `/approve all` | одобрить — уйдёт по расписанию |
| `/skip 5` | не публиковать |
| `/publish 5` | опубликовать сейчас |
| `/status` | сколько постов в каком статусе |

## Защита от ошибок
- Ничего не уходит в канал без одобрения.
- Пост не публикуется дважды: факт публикации хранится отдельно от таблицы (`state.json`),
  поэтому даже если `posts.csv` открыт в Excel и заблокирован — повтора не будет.
- Бот был выключен и пропустил время поста больше чем на 12 часов — сам публиковать не станет
  (иначе в канал вывалится пачка старых постов), а напишет вам.
- Генерация не выдумывает кейсы и цифры: в бриф кладутся только реальные факты, в правилах — запрет.
